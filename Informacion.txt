# Historial de Prompts del Proyecto FitCat

--- PROMPT 1 ---
"Actúa como un Desarrollador Senior de Mobile. El objetivo es construir 'FitCat', una aplicación móvil de entrenamiento personal que permita a los usuarios gestionar sus rutinas de fuerza y salud.
Contexto de la App: La aplicación debe estar diseñada para usuarios que entrenan en el gimnasio o en casa. Necesitamos que el contenido de ejemplo incluya categorías como 'Tren Superior', 'Tren Inferior' y 'Cardio'.
Configuración Técnica: Inicializa un proyecto de React Native con Expo con una arquitectura de carpetas profesional (src/screens, src/navigation, src/components). Instala y configura @react-navigation/native y @react-navigation/bottom-tabs.
Navegación y Pantallas (Tabs): Dashboard, Entrenar, Historial, Ejercicios, Progreso.
Estilo Visual: Aplica una paleta de colores 'Espacial': Fondos negro mate (#0B0B0E), acentos en morado eléctrico (#8A2BE2) y detalles en violeta neón. Usa lucide-react-native para iconos minimalistas. La UI debe usar tarjetas (Cards) con bordes redondeados y tipografía moderna.
Objetivo: Crea la base visual navegable. No incluyas bases de datos ni lógica de guardado real aún, solo la estructura para validar el flujo."
